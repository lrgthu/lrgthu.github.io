Static personal webpage for Ruogu (Franklin) Lin.

Open `index.html` locally, or publish this repository with GitHub Pages.

Important GitHub Pages note: the authenticated GitHub account seen locally is `lrgthu`. A repository named `lrg.github.io` under that account will normally publish as:

```text
https://lrgthu.github.io/lrg.github.io/
```

For the root user-site URL, GitHub expects the repository name to match the account exactly:

```text

```
